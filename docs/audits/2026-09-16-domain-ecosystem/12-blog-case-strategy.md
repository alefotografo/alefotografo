# 12 — Estratégia Case + Blog (relação editorial)

Data: 16/09/2026 · Regra central: **CASE ≠ BLOG**.

- **CASE** = prova comercial (portfólio). Cliente, contexto, desafio, execução, galeria, aplicações.
- **BLOG** = artigo editorial sobre o mesmo trabalho real. Bastidores, decisões, problema visual, processo, aprendizados, técnica, setor.
- NUNCA copiar o texto do Case no Blog. Intenções de busca diferentes → páginas diferentes, links naturais entre elas.

## Arquitetura de crosslink futura (padrão)

```
BLOG (bastidores/editorial)
   ↕ link natural "ver o case completo"
CASE (prova comercial)
   ↕ links para
SERVIÇO (página de venda)
   ↕
NICHO (cluster setorial, ex.: logística)
   ↕ quando houver vídeo
VC (case audiovisual do mesmo projeto)
```

Âncoras naturais; sem excesso de match exato; nunca sitewide.
