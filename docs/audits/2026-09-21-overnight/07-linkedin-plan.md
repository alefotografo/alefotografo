## Diagnóstico

1. **Página comercial forte:** /foto-profissional-para-linkedin (GEO 3/3; 979 palavras; FAQ; recortes prontos; 20-40min/pessoa; ≤1 dia útil). Recebe só 195 impr no GSC Pages — **a demanda do cluster está indo para outras URLs** (home, posts, /foto-profissional).
2. **SERP proxy "foto para linkedin": ALE ausente no top 7.** Top: blog fotoslinkedin.com.br (prompts IA), waalaxy (geradores), fotoparalinkedin.com (Peru). A intenção genérica foi capturada por conteúdo de IA; fotógrafos BR ausentes — espaço aberto.
3. **Ativos editoriais que ranqueiam:** post 7-erros-foto-perfil-linkedin (150 cl · 72 mil impr) · foto-para-linkedin-o-que-funciona (3 cl) · capa-linkedin post (24 cl) · 5-fatores-perfil-linkedin (3 cl) · maximizar-perfil-linkedin (4 cl).
4. **"capa linkedin" (1.157 impr pos 10,11):** intenção satélite com página própria inexistente; o post de capa do LinkedIn cobre parcialmente.
5. **fotosprofissionais.com.br (owned):** cita LinkedIn como uso de retrato mas não tem página dedicada — não compete nem captura (02).

## Plano (não implementado)

1. **P1 — Internal links:** os 5 posts do cluster ganham link contextual para /foto-profissional-para-linkedin com âncoras naturais ("ensaio para LinkedIn", "foto de perfil profissional") — mapa em 16. Máx. 1–2 links por post.
2. **P1 — Cross-link da página de foto profissional:** /foto-profissional (que absorve a query "foto profissional linkedin", 695 impr) ganha bloco/link para a página LinkedIn (conversão de intenção híbrida).
3. **P2 — "capa linkedin":** post existente pode receber atualização factual de dimensões (conteúdo editorial legítimo) + link para a página de serviço. NÃO criar página comercial para capa (intenção informacional).
4. **P2 — Diferencial factual na página:** recortes quadrado/vertical/horizontal prontos e "time todo no mesmo dia" já são citable facts fortes (04); considerar (em missão de conteúdo) adicionar 1 cliente nomeado quando houver case publicado.
5. **P3 — Test pack GEO:** executar prompts 17/18/53 do pack (25) para medir se IAs citam a página para "foto para LinkedIn".

## Riscos

- Não criar página nova (a existente é forte; criar segunda URL diluiria).
- Não reescrever o post 7-erros (150 cl) — adicionar link no corpo com contexto, nada mais.
- Apps de IA dominam a intenção genérica: a resposta comercial do Ale é a página + prova; não competir em "gerar foto com IA".
